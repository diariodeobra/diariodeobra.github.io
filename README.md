# Diário de Obra ECTAS

App: **https://instalacao-ectas.github.io** (endereço novo desde 12/11/2026; este endereço só encaminha para lá)

Registro diário de obra (RDO) no celular, com fotos e legendas, enviado ao grupo da obra no WhatsApp em PDF, Word ou fotos com texto.
Instale pelo Chrome (Android: Instalar) ou Safari (iPhone: Compartilhar > Adicionar à Tela de Início).

Os registros ficam salvos só no celular de quem usa. Nenhum RDO ou foto fica neste repositório.
